 GUÍA DE DISTRIBUCIÓN - Bot Didi (Versión Ejecutable)
════════════════════════════════════════════════════════════════

✨ VENTAJA: Esta versión NO requiere que el usuario instale Python
   Todo está compilado en ejecutables (.exe) listos para usar


🔨 PASO 1: COMPILAR LOS EJECUTABLES (Solo tú, una vez)
════════════════════════════════════════════════════════════════

1. Ejecuta: COMPILAR_EJECUTABLES.bat
2. Espera 5-10 minutos (compilación puede tardar)
3. Se crearán los archivos en carpeta dist/:
   • Didi.exe (~80-100 MB)
   • backend_conteo.exe (~30-40 MB)
   • ver_datos.exe (~20-30 MB)
   • test_conexion.exe (~20-30 MB)

IMPORTANTE: Solo necesitas hacer esto UNA VEZ, o cuando
            actualices el código fuente.


📦 PASO 2: CREAR EL PAQUETE DE DISTRIBUCIÓN
════════════════════════════════════════════════════════════════

1. Asegúrate de haber compilado los ejecutables (Paso 1)
2. Ejecuta: CREAR_PAQUETE_EXE.bat
3. Se creará:
   • Carpeta: BotDidi_Ejecutable_v1.0/
   • Archivo ZIP: BotDidi_Ejecutable_v1.0.zip (~150-200 MB)


🚀 PASO 3: DISTRIBUIR AL USUARIO FINAL
════════════════════════════════════════════════════════════════

Opción A: Envía el archivo .zip
   - Por correo (si es menor a límite del correo)
   - Por Google Drive / OneDrive / Dropbox
   - Por WeTransfer (archivos grandes)

Opción B: Copia a USB
   - Copia la carpeta BotDidi_Ejecutable_v1.0 a USB
   - Entrega la USB al usuario

Opción C: Red local
   - Comparte la carpeta en red
   - Usuario copia a su PC


👤 PASO 4: INSTRUCCIONES PARA EL USUARIO FINAL
════════════════════════════════════════════════════════════════

Dile al usuario que:

1. Extraiga/copie TODOS los archivos a una carpeta
   (Ejemplo: C:\BotDidi)

2. Ejecute: INSTALAR.bat
   (Verifica Chrome y conexión - toma 10 segundos)

3. Lea con atención: INSTRUCCIONES_USUARIO.txt

4. Siga los 3 pasos del uso diario:
   a) abrir_chrome_debug.bat (primera vez)
   b) INICIAR_BOT.bat (para usar)
   c) VER_ESTADISTICAS.bat (para ver resultados)

🆘 SOPORTE COMÚN - PROBLEMAS Y SOLUCIONES
════════════════════════════════════════════════════════════════

Error: "Didi.exe no se ejecuta"
→ Windows Defender puede bloquearlo la primera vez
→ Solución: Click derecho > "Ejecutar de todas formas"
→ O agregar excepción en Windows Defender

Error: "El archivo es muy grande"
→ Es normal, los .exe incluyen Python embebido
→ Tamaño: ~150-200 MB total

Error: "Chrome no encontrado"
→ Usuario debe instalar Google Chrome
→ https://www.google.com/chrome/

Error: "No se pudo conectar a Chrome"
→ Usuario debe ejecutar abrir_chrome_debug.bat primero
→ Y dejar ese Chrome abierto

Error: "No guarda los datos"
→ Verificar conexión a internet
→ Firewall puede estar bloqueando
→ Verificar que tabla existe en BD
