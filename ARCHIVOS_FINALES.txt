🎯 CÓMO USAR LOS ARCHIVOS
════════════════════════════════════════════════════════════════

PASO 1: Compilar (5-10 minutos)
───────────────────────────────
Ejecuta: COMPILAR_EJECUTABLES.bat

Esto leerá:
  - Didi.py
  - backend_conteo.py
  - ver_datos.py
  - test_conexion.py

Y generará en dist/:
  - Didi.exe
  - backend_conteo.exe
  - ver_datos.exe
  - test_conexion.exe


PASO 2: Crear paquete (1 minuto)
─────────────────────────────────
Ejecuta: CREAR_PAQUETE_EXE.bat

Esto creará carpeta con:
  - Los 4 .exe compilados
  - INSTALAR.bat (de INSTALAR_EXE.bat)
  - INICIAR_BOT.bat (de INICIAR_BOT_EXE.bat)
  - VER_ESTADISTICAS.bat (de VER_ESTADISTICAS_EXE.bat)
  - abrir_chrome_debug.bat
  - Documentación para usuario

Y comprimirá todo en:
  - BotDidi_Ejecutable_v1.0.zip


PASO 3: Distribuir
───────────────────
Envía el ZIP al usuario final


💡 NOTAS IMPORTANTES
════════════════════════════════════════════════════════════════

1. NO borres los archivos .py
   → Son necesarios para compilar los .exe

2. Los archivos *_EXE.bat se renombran automáticamente
   → El script CREAR_PAQUETE_EXE.bat se encarga

3. Si actualizas el código:
   → Modifica el .py
   → COMPILAR_EJECUTABLES.bat (recompila)
   → CREAR_PAQUETE_EXE.bat (nuevo paquete)

4. La carpeta ChromeProfile/ se crea automáticamente
   → No la incluyas en el paquete

5. Las carpetas build/ y dist/ se crean al compilar
   → No las incluyas en control de versiones
